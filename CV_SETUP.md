# CV Files Setup

The portfolio requires PDF versions of your CV in both French and English.

## Required Files in `public/` Directory

- **French CV**: `cv-nourhene-chalghoumi-fr.pdf` ✓ (Already exists)
- **English CV**: `CV_Nourhene_Chalgoumi_EN.pdf` ⚠️ (Needs to be added)

## Instructions to Add English CV

1. Convert your English CV to PDF format
2. Name it exactly: `CV_Nourhene_Chalgoumi_EN.pdf`
3. Place it in the `public/` directory at the root of the project
4. The download button will then work automatically

## File Specifications
- Format: PDF (.pdf)
- Maximum size: 5MB recommended
- File names must match exactly (case-sensitive on Linux/Mac)
